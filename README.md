# Charoite Current

Full-colour Python 3 neon tide-hopper for [ElbowOS](https://x.com/ElbowOS).

A cream moth hops drifting copper logs on a lilac charoite river. Mint pearls score. Coral eels punish a splash. Reach the gold beacon to bank a crossing and speed the current.

A / D or Left / Right drift. Space / W / Up hops.

## Play

```bash
pip install -r requirements.txt
python3 charoite_current.py --play
```

## Record a 9:16 reel

```bash
python3 charoite_current.py --record
```

Writes a 1080x1920 h264 clip (15s @ 30fps) with title, score, and `x.com/ElbowOS` burned into the frames.
